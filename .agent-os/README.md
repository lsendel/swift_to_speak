# Agent OS Configuration

This directory contains the Agent OS configuration for the VoiceFlow AI project.

## Overview

Agent OS orchestrates specialized AI agents to handle different aspects of the VoiceFlow AI development lifecycle:

- **Voice Pipeline Architect**: Optimizes speech processing and audio pipelines
- **iOS Specialist**: Handles iOS-specific development and optimization
- **Speech API Integrator**: Manages multiple speech service providers
- **AI Personality Designer**: Crafts the engaging personality system
- **Infrastructure Orchestrator**: Manages cloud deployment and scaling
- **Security Guardian**: Ensures privacy and compliance
- **Cross-Platform Coordinator**: Maintains consistency across platforms

## Configuration

The main configuration file `config.yaml` defines:
- Agent roles and responsibilities
- Development workflows and phases
- Automation triggers and actions
- Monitoring metrics and thresholds
- Communication channels and reporting

## Getting Started

1. Ensure all environment variables are set (see config.yaml)
2. Initialize agents: `agent-os init`
3. Start development workflow: `agent-os workflow start development`
4. Monitor progress: `agent-os status`

## Integration

Agent OS integrates with:
- GitHub for version control
- Slack for team notifications
- AWS for infrastructure management
- Multiple speech service providers

For detailed documentation, see the `/product` directory.
